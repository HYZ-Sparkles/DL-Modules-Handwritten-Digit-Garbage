# 模型改进优化计划

## 四、最佳模型配置

**最终推荐模型：LeNet5 + LoRA(r=8) + ELU**
- 准确率：72.31%（超越基准 71.15%）
- 提升：+1.16%
- 结构：在 conv2 后、fc1 前添加 LoRA 低秩适配器，使用 ELU 激活函数
- 预训练权重加载：conv1, conv2, fc1, fc2 正常加载，只有 fc3 和 lora 参数随机初始化
